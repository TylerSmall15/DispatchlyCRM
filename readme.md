# 🚀 Dispatchly Pro

**Dispatchly Pro** is a **digital operations manager for blue-collar service businesses** — designed to help plumbing, HVAC, and restoration companies run smarter, faster, and more profitably.

With built-in tools for job scheduling, lead tracking, crew assignments, client management, and more, Dispatchly Pro replaces paperwork, missed calls, and scheduling chaos with clarity and control.

---

## 🧰 Tech Stack
- **Frontend:** Next.js (React, TypeScript)
- **Backend:** Supabase (Postgres, Auth, Storage)
- **UI Framework:** Tailwind CSS + shadcn/ui
- **Hosting:** Vercel
- **Integrations (Planned):** QuickBooks, Stripe, Zapier

---

## ✨ Core Features
- 📊 **Dashboard Overview:** Real-time view of leads, jobs, and revenue activity  
- 🧾 **Job Management:** Schedule, assign, and track every job from start to completion  
- 📞 **Lead Tracking:** Follow leads through contact, quotes, and closure  
- 🧑‍🔧 **Contractor Management:** Add and assign employees or subcontractors to specific jobs  
- 🏢 **Company & Client CRM:** Keep commercial clients and residential homeowners organized  
- 🌐 **Website Integration:** Capture leads directly from client websites  
- 💵 **Invoicing (Coming Soon):** QuickBooks & Stripe integration for seamless billing
